# XGBoost — Credit Risk Prediction

This project predicts whether a customer is likely to default on a loan using the XGBoost algorithm.

## Features
- Data preprocessing
- Feature scaling
- XGBoost model training
- Model evaluation
- Feature importance visualization
- Save trained model

## Target
Default
0 → Low Risk
1 → High Risk

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run notebook

jupyter notebook notebook/credit_risk_xgboost.ipynb
