# NLP Sentiment Analysis — Movie Reviews

This project performs sentiment analysis on movie reviews using Natural Language Processing (NLP).

The model classifies reviews as Positive or Negative.

Tech Stack:
- Python
- Scikit-learn
- TF-IDF
- Logistic Regression
- Pandas

## Dataset:
IMDB Movie Reviews Dataset (50K reviews)

## Project Workflow:
1. Data Cleaning
2. Text Vectorization using TF-IDF
3. Model Training (Logistic Regression)
4. Model Evaluation
5. Sentiment Prediction

## Accuracy:
~89%

## Example:

### Input:
"This movie was amazing"

### Output:
Positive
